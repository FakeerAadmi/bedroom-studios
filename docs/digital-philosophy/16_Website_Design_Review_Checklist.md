# 16. WEBSITE DESIGN REVIEW CHECKLIST
**The Gatekeeping Framework for Digital Pages and Features**
*Version 1.0 — Autumn 2026*

---

## HOW TO USE THIS FRAMEWORK
Before any new webpage, component, or interaction is merged into production for Bedroom Studios, it must be evaluated against this **20-point binary checklist**. 

Every inquiry requires a verified **YES** or **UNACCEPTABLE**. A single failure halts deployment.

---

## 1. ATMOSPHERE & BRAND IDENTITY (THE ROOM TEST)

- [ ] **1.1 The Studio Atmosphere**: Does this page feel like an architectural sanctum at dusk, or does it look like a generic e-commerce template?
- [ ] **1.2 Object as Hero**: Are the physical objects the primary visual focus, presented with accurate scale, material texture, and real contact shadows?
- [ ] **1.3 Color Discipline**: Does the page adhere strictly to the 5-tier color system (Obsidian, Parchment, Mineral Grey, Brass, Amber)? Zero unapproved gradients or neon distractions.
- [ ] **1.4 Cultural Restraint**: Is the design free of both ethnic tourist kitsch and sterile Scandinavian pastiche?

---

## 2. INTERACTION & MOTION PURPOSE (THE CAUSE & EFFECT TEST)

- [ ] **2.1 Purpose of Motion**: Does every animation have a clear functional reason (spatial orientation or physical kinetic transfer)?
- [ ] **2.2 Mass & Damping**: Do moving elements move with realistic mass and inertia, avoiding cartoonish elastic overshoots?
- [ ] **2.3 The No-Animation Test**: If all animations were disabled, does the page still function cleanly, logically, and beautifully?
- [ ] **2.4 Audio Discipline**: Is audio strictly confined to the physical pull-chain switch, operating via calibrated Web Audio with zero intrusive chimes?

---

## 3. COMMERCIAL USABILITY & CLARITY (THE UTILITY TEST)

- [ ] **3.1 Price Transparency**: Is the Indian Rupee (`₹`) price immediately visible, formatted with Indian numbering, and all-inclusive of taxes?
- [ ] **3.2 Frictionless Purchase**: Can a user add an item to the bag and complete an order inquiry in under 3 deliberate steps?
- [ ] **3.3 Lead Time Clarity**: Are production and dispatch times clearly stated for made-to-order objects?
- [ ] **3.4 Dark Pattern Free**: Is the page 100% free of fake countdown timers, fake inventory alerts, and exit-intent popups?

---

## 4. ACCESSIBILITY & PERFORMANCE (THE DIGNITY TEST)

- [ ] **4.1 The Experiential Bypass**: Can keyboard-only and assistive technology users bypass theatrical intros via a prominent "Skip to Content" mechanism?
- [ ] **4.2 Keyboard Operability**: Is every interactive button, link, and slider fully navigable and operable via `Tab`, `Enter`, and `Space`?
- [ ] **4.3 Contrast Verification**: Do all text elements meet or exceed WCAG 2.1 AA contrast ratios (≥ 4.5:1 for body, ≥ 3.0:1 for large headers)?
- [ ] **4.4 Vestibular Safety**: Does the page respect `prefers-reduced-motion` by disabling spring animations and multi-second camera transitions?
- [ ] **4.5 Performance Budget**: Does the page achieve Core Web Vitals targets: LCP < 1.8s, CLS = 0, and FID/INP < 100ms?

---

## 5. LAYOUT & SPATIAL INTEGRITY (THE ARCHITECTURAL TEST)

- [ ] **5.1 12-Column Grid Alignment**: Do all elements align to the defined 12-column architectural matrix?
- [ ] **5.2 Generous Negative Space**: Is there ample vertical breathing room (96px–160px on desktop) between major narrative sections?
- [ ] **5.3 Typographic Discipline**: Are uppercase elements properly tracked out (+0.18em) and large headers tightened (-0.02em)?
- [ ] **5.4 Mobile Ergonomics**: Are all mobile touch targets at least 44px × 44px, with primary action buttons anchored in the natural thumb zone?

---

## APPROVAL VERDICT
- **20 / 20 PASS**: Approved for production deployment.
- **ANY FAILURE**: Returned to design/development branch with specific citation.
